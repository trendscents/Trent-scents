Trend Scents website
Static site, no build step.
Publish on GitHub Pages
Create a repository, upload everything in this folder (keep the `assets` folder).
Settings > Pages > Source: Deploy from a branch > `main` / root > Save.
Your site appears at `https://YOURNAME.github.io/REPO/` in about a minute.
Edit the site
Open `assets/data.js`: prices, offer, ticker (new trends), reviews, WhatsApp number.
New perfume: add its image to `assets/img/` and copy a product block in `data.js`.
